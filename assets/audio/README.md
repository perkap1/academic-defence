# Original cartoon effects

Nine original cartoon effects generated by tools/generate_cartoon_sounds.py. Filtered noise, air swishes, damped wood-like resonances, rubbery pitch glides and short room tails. No third-party samples, square waves or 8-bit quantization.

Mono PCM WAV at 44100 Hz / 16 bit, no loops, peak amplitude capped at 0.22. Runtime voice gain, default volume, mute, saved settings, rate limits and ten-voice pool are unchanged.

Book: airy swish and soft paper thwap. Science: bubble launch and wet splat. PE Teacher: heavy whoosh and rubber poff. Shared: wooden building clunk, rising upgrade plucks and a soft graduation chime.

The older generate_8bit_sounds.py is retained as a source reference for the previous style. Use generate_cartoon_sounds.py to regenerate the current assets.
