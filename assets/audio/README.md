# Original 8-bit effects

Nine original effects synthesized by tools/generate_8bit_sounds.py using pulse waves, pitched tones and deterministic noise. No third-party recordings or samples.

Mono PCM WAV, 22050 Hz / 16-bit container with an 8-bit-quantized waveform. Short attack/release envelopes avoid clicks, no loops, peak amplitude 0.22. Runtime voice gain is -8 dB, with a separate Effects bus and a default volume of 55%.

Book: throw and hit. Science: throw and impact. PE Teacher: throw and burst. Shared: build, upgrade/specialization and graduation.
